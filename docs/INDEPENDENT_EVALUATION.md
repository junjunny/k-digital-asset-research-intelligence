# Independent Evaluation

기준일: 2026-11-17

## 실험 설계

Group A는 K-DAPI를 제공하지 않은 fresh 독립 에이전트, Group B는 같은 질문과 웹 조건에서 격리 소비자 프로젝트의 설치본만 제공한 fresh 독립 에이전트다. 양쪽 모두 개발 프롬프트, 과거 사례 결론, 평가 정답, 상대 답변을 받지 않았다. 각 사례의 질문·답변·출처·접근 제한은 `evaluations/phase-8/cases/`에 원문으로 보존했다.

완전한 실험 통제는 아니다. 실행 환경이 구체 모델 ID, seed, temperature, 토큰 수와 실행시간을 노출하지 않았고 반복 실행도 1회씩만 수행했다. 따라서 관찰된 차이를 오직 스킬의 인과효과로 확정할 수 없다.

## A/B 결과 요약

| 사례 | 공통 성과 | 설치본 사용군에서 두드러진 점 | 남은 쟁점 |
|---|---|---|---|
| CLARITY | 미제정 상태, 미국 기관권한, 한국 현행·예정·정책 구분 | 공식 상원 보고본과 별도 S.3755를 분리, claim 상태 표시 | 의원실 9월 협상 초안의 위치와 최신 공식 입법기록 확인 |
| Chainlink | 실제 서비스, pilot/production, 토큰 수요와 채택 분리 | 공급 API·방출률·Reserve·staking 범위와 미확인 단위경제성 명시 | 계약매출·LINK 전환액·실제 CCIP 사용량 비공개 |
| Ethereum | EL/CL, PoS, L1/L2, 실측/상한, 집중 위험 분리 | 사실·추론·미확인, 미확정 업그레이드와 한국 무관성 표시 | 대시보드 정의·entity tagging·L2 포함 범위 변동 |
| USDC | 상환/시장가, 준비금, attestation/audit, 한국 개인 위험 구분 | 주간 자체공시와 월간 외부 examination의 검증수준 분리 | 동적 최신 수치·은행별 익스포저·개별 한국법 적용 |

일반 대조군 답변도 네 사례 모두 상당히 강했다. 스킬 사용이 항상 우월하다고 결론 내리지 않는다. K-DAPI의 관찰 가능한 부가가치는 주로 상태·출처 성격·사실/추론/미확인·한국 관련성의 경계를 일관되게 표시한 점이었다. 가독성에서는 설치본 사용군이 더 길고 전문적이어서 일반 사용자에게 항상 유리하다고 볼 수 없다.

## 설치와 활성화

- 탐지·설치: 성공
- 명시적 사용: 성공. 네 독립 Group B 세션이 설치본 진입점과 필요한 참조문서를 읽고 답변 생성
- 자동·암묵 활성화: 관측 불가. 지원 에이전트 UI의 활성화 이벤트·로그가 없어 완료로 주장하지 않음
- 입력부터 최종 답변: 네 필수 질문 모두 실제 수행

## 사용성·대화·오프라인

수정 전 열 문항에서 다섯 라우팅 오류를 기록했고 최소 수정 후 같은 문항과 holdout으로 재검증했다. 다중 턴 세 시나리오는 이미 확인한 대상과 깊이를 유지했다. 웹 미사용 질문은 최신 입법상태를 단정하지 않고 검증 불가와 확인 경로를 먼저 밝혔다.

다중 턴은 독립 에이전트의 연속 대화 응답 평가이며 자동화된 상태 서버 E2E가 아니다. 오프라인은 웹 도구를 제공하지 않은 행동 평가이며 OS 네트워크를 강제로 차단한 통합 시험은 아니다.
