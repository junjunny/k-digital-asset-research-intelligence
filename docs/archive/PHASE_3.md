# Phase 3 — Real Case Study

사례: EIB의 2023년 £50m sterling digital bond와 한국 토큰증권 제도화 비교.

산출물은 `examples/tokenization-case-study/`의 국문 보고서, 영문 Executive Summary, Evidence JSON, Report JSON이다. EIB 발행이 EU DLT Pilot 적용 전이었다는 시간 관계를 명시했고, 한국 개정법은 공포됐지만 2027-02-04 시행 예정이며 2026-10 하위법규는 입법예고라는 상태를 분리했다.

자동 검증은 통과했으며, 개별 상품 출시 전 최종 하위법규·인가·세무·회계·외국환·계약 책임은 전문가 추가 검토가 필요하다.
