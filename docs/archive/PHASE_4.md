# Phase 4 — Open-source Release

## 로컬 완료

- 한국어·영어 README
- MIT License
- 설치·사용·테스트 명령
- 공개 가능한 예시 보고서와 구조화 근거
- `.gitignore` 및 민감정보 없는 코드 구조

## 공개 전 확인

- GitHub push 후 README 링크와 설치 명령 확인
- 공개 저장소에서 fresh clone 테스트
- `npx skills add` 실제 설치 테스트
- skills.sh 등록·검색 노출 확인
- 사례 보고서의 법률·정책 상태 최종 수동 검토

공개 push와 skills.sh 등록은 별도 사용자 요청 또는 승인 범위에서 진행한다.
