# Superseded Plan — Independent Natural-language Evaluation

상태: 2026-11-17 새 Phase 7 일반 사용자 라우터 계획으로 대체됨. 삭제하지 않고 이력을 보존한다. 아래 독립 평가 범위는 Phase 8 후보이며 사용자 승인 전 실행·구현하지 않는다.

## 목적

저장된 보고서의 재검증이 아니라, 격리 설치된 K-DAPI가 처음 보는 자연어 질문을 받아 주제 분류부터 공식 자료 탐색, 한국 비교, 사실·추론·미확인 구분, 최종 답변 생성까지 수행하는지 평가한다.

## 필수 입력

> 미국 CLARITY Act를 분석하고 한국 디지털자산 규제와 비교해 줘.

“CLARITY Act”라는 이름이 가리키는 법안과 회기를 먼저 식별한다. 실행 시점의 미국 의회 공식 원문, 법안 번호, 최신 action/status, 수정본을 조회하기 전에는 통과·제정·시행 여부를 서술하지 않는다. 한국 비교도 같은 분석 기준일의 국가법령정보센터·국회·금융위원회 등 공식 원문을 새로 확인한다.

## 격리 조건

1. GitHub 기본 브랜치를 새 임시 디렉터리에 clone한다.
2. 별도 프로젝트 범위에 `npx skills add`로 설치한다.
3. EIB·홍콩 보고서 내용은 평가 정답이나 프롬프트에 제공하지 않는다.
4. 새 에이전트 세션은 필수 입력과 일반 사용자 맥락만 받는다.
5. 웹 검색 가능 여부, 검색 시각, 사용 도구, 공식 원문 URL을 기록한다.
6. 웹 검색이 불가능하면 최신 검증 불가를 명시하는지가 평가 대상이며, 과거 지식으로 상태를 단정하면 실패다.

## 관찰할 전체 흐름

1. 질문을 해외 법률·규제 비교 유형으로 분류한다.
2. 분석 깊이와 기준일을 정하고 불필요한 PDF·API 키를 요구하지 않는다.
3. 미국 공식 법안 원문·의회 진행상태·관련 기관 자료를 찾는다.
4. 한국의 관련 현행법·시행 예정법·법률안·정책을 각각 확인한다.
5. 비교 가능한 규율 대상과 개념만 대응시키고 제도 차이를 설명한다.
6. 검증된 사실, 지원되는 추론, 미확인·추가 검토를 분리한다.
7. 간결한 요청에는 과도한 장문 보고서를 만들지 않되 비교에 필요한 핵심은 포함한다.

## 자동 평가

- 모든 핵심 법적 주장에 Evidence ID 또는 직접 공식 출처가 연결됨
- 법안 상태와 `claim_type`·`legal_status`가 분석 기준일에 일치함
- 서로 다른 관할권 Evidence가 뒤섞이지 않음
- `VERIFIED_FACT`가 원문 접근·발췌 일치 요건을 충족함
- 구조화 산출물을 만든 경우 스키마와 validator를 통과함
- 저장된 사례 테스트가 아니라 실제 실행 로그와 새 산출물이 존재함

## 인간 평가

- CLARITY Act의 적용 대상·권한 배분·핵심 의무를 문맥에 맞게 설명했는가?
- 미국 법안과 한국 제도를 기능적으로 비교했는가, 이름이 비슷한 개념을 억지로 대응시켰는가?
- 현행법, 시행 예정법, 법률안, 정책을 구분했는가?
- 한국 연결이 실질적이며 과도한 토큰증권 프레임을 적용하지 않았는가?
- 반론·예외·불확실성을 충분히 밝혔는가?
- 일반 사용자가 이해할 수 있고 질문 깊이에 맞는가?

## 치명적 실패

- 공식 원문 조회 없이 법안이 통과·제정·시행 중이라고 단정
- 다른 회기·다른 법안을 같은 CLARITY Act로 혼동
- 미국 법안을 한국 현행법처럼 표현하거나 반대로 표현
- 정책 발표·입법예고를 법률로 표현
- 검색 불가 상태에서 최신 검증을 가장함
- 출처에 없는 법적 결론이나 사용자 의견을 생성

## 합격 결정

자동 검증 통과만으로 합격하지 않는다. 사용자가 지정한 인간 평가자가 공식 원문과 최종 답변을 대조하고 치명적 실패가 없으며 핵심 평가 항목을 충족했다고 승인해야 한다. 평가자와 점수 기준은 Phase 7 시작 전에 사용자가 결정한다.
