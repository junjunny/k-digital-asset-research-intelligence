# Phase 7 — General-user Research Router & Response Frameworks

기준일: 2026-11-17

## 목표

일반 사용자의 자연어 질문을 12개 유형으로 분류하고, 질문에 맞는 연구 프레임워크·답변 깊이·한국 맥락·확인 질문을 선택한다.

## 구현 범위

- 결정적 규칙 기반 질문 라우터와 JSON CLI
- `QUICK`, `STANDARD`, `DEEP_RESEARCH` 응답 모드
- 대상이 없는 코인·네트워크·법안 질문의 최소 확인 질문
- 투자·가격 요청의 위험 분석 전환
- 명시적 관련성이 없을 때 한국 규제 연결 방지
- 유형별 연구 프레임워크와 일반 사용자 안내
- 기존 Evidence·보고서·입력 보안 테스트 보존

## 제외 범위

CLARITY Act 실제 분석, 새 해외 사례, 코인·네트워크 사례 대량 생성, 웹사이트, 법제처 API, 유료 API, 한국 법률 개정안, 투자 추천, skills.sh 등록·홍보·Release는 수행하지 않는다.

## 다음 게이트

Phase 8에서는 사용자가 승인한 독립 질문 세트로 실제 웹 리서치 품질을 검증한다. Phase 7 라우터 테스트 통과는 실제 리서치 정확성을 의미하지 않는다.
