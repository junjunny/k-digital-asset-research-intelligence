## 반복적으로 발견된 문제

1. 법안·절차표결·현행법, 공포됐으나 미시행인 법률, 입법예고안을 한 단계로 표현했다.
2. 프로젝트 자체 지표·보도자료를 상대 기관 또는 독립 자료가 확인한 사실처럼 확대했다.
3. 공급량·Reserve·staking·준비금·네트워크 활동량에 관측 시각과 산식이 빠졌다.
4. 파일럿·제한 생산·상용 출시·지속 운영을 구분하지 않았다.
5. 거래소의 공개 정성 기준을 비공개 점수표나 법정 상장 요건처럼 구체화했다.
6. 토큰증권의 가능한 수익원을 실제 국내 매출·마진·비용절감 실적으로 바꿨다.

## 120개 외 검토 대기 항목

### Phase 8 A/B 8개 답변

기존 모델 보조평가는 CLARITY 94/98, Chainlink 97/98, Ethereum 95/98, USDC 96/98이고, 네 사례 모두 설치본 사용 답변을 선호했다. 이번 1차 자료 감사는 공식 상원 표결, LINK 공급·Reserve, Ethereum 업그레이드·집중도, USDC 직접상환·examination 범위를 보완했다. 다만 기존 점수는 인간 점수로 변경하지 않았고 `docs/PHASE_8_HUMAN_REVIEW.md`의 승인란도 비워 뒀다.

### EIB·홍콩 디지털채권

`docs/RESEARCH_QUALITY_AUDIT.md`의 14개 평가 항목은 모두 `부분 충족`이다. 룩셈부르크 직접 법적 근거, 홍콩 거래별 적용 법령·법률의견, 비용·유동성·수요·수익성, 외국환·세무·회계, 장애복구와 원장 불일치 책임은 공개 자료만으로 종결할 수 없다. AI가 임의로 완료 처리하지 않았다.

### 네이버 AI 외부 벤치마크

CLARITY와 Ethereum 기록은 `USER_RECONSTRUCTED`, `ORIGINAL_CAPTURE_MISSING`이다. 원 질문·실행시각·제품명·원본 캡처가 없어 원본성 검증은 불가능하다. 공식 근거 대조는 유지하되 인간 검증 완료로 바꾸지 않았다.
