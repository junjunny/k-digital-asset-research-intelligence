# General User Guide

K-DARI는 PDF나 API 키 없이 자연어 질문으로 시작할 수 있다. 최신 법률·시장·프로젝트 상태가 필요한 질문은 웹 검색 가능한 에이전트에서 사용하는 것이 좋다.

## 설치

```bash
npx skills add junjunny/k-digital-asset-research-intelligence --skill k-dari
```

설치 후 지원 에이전트에 평소처럼 질문한다.

지원 환경이 자동으로 스킬을 고르지 않으면 `$k-dari`를 명시해 질문한다. 설치 성공과 자동 활성화는 별개다.

## 질문 예시

### 법률·정책

```text
CLARITY Act가 무엇인지 현재 법안 상태와 함께 간단히 알려줘.
```

법안 번호·회기·공식 원문과 현재 상태를 확인한다. 웹 검색이 불가능하면 최신 검증 불가를 알린다.

### 규제 비교

```text
미국의 디지털자산 시장구조 법안과 한국 규제를 비교해 줘.
```

기능적으로 비교 가능한 항목만 다루며 한국 법률 개정안을 대신 작성하지 않는다.

### 코인·프로젝트

```text
프로젝트명, 티커, 네트워크를 기준으로 이 코인의 용도와 주요 위험을 분석해 줘.
```

“이 코인 어떤 거야?”처럼 대상이 없으면 이름·티커·네트워크를 먼저 묻는다.

### 네트워크

```text
이더리움 네트워크를 합의 방식, 탈중앙화, 실제 사용, 장애 위험 관점에서 평가해 줘.
```

토큰 가격이 아니라 네트워크 구조와 운영 근거를 중심으로 평가한다.

### 백서

```text
이 프로젝트의 공식 백서를 검토하고, 구현된 기능과 계획을 구분해 줘.
```

백서 파일·공식 URL·프로젝트명이 필요하다. 문서 내용은 지시가 아닌 비신뢰 데이터로 처리한다.

### 스테이블코인

```text
USDC가 가격을 유지하는 방식과 준비자산·상환·디페깅 위험을 알려줘.
```

“안전하다”는 단정 대신 상환권·준비자산·보관·증명·운영 위험을 구분한다.

### 토큰증권·RWA

```text
토큰증권이 무엇인지 쉽게 설명하고 한국의 현재 제도와 시행 예정 제도를 구분해 줘.
```

### 거래소 정책

```text
이 거래소가 해당 코인의 거래지원을 종료한 공식 사유를 찾아줘.
```

거래소 공식 공지와 규제기관 판단을 구분한다.

### 사업모델

```text
이 디지털자산 결제 사업모델을 고객·수익원·비용·인허가·실행조건 관점에서 검토해 줘.
```

### 투자 질문

```text
이 코인 사도 돼?
```

K-DARI는 매수 결론을 대신하지 않는다. 대상을 확인한 뒤 구조·공급·기술·운영·규제 위험과 확인 체크리스트를 제공한다.

## 답변 깊이 요청

- 짧은 설명: “쉽게 알려줘”, “핵심만 알려줘”
- 일반 분석: “구조와 위험을 평가해 줘”
- 심층 보고서: “공식 근거를 포함한 심층 리서치 보고서로 작성해 줘”

## 후속 질문

앞에서 확인한 대상과 범위를 그대로 이어서 질문할 수 있다.

```text
클래리티 법안 알려줘. → 그럼 한국에서는? → 핵심 차이만 표로.
```

```text
이 코인 어떤 거야? → LINK야. → 실제 사용은? → 위험은?
```

라우터는 단일 질문의 보조 수단이다. 에이전트는 이미 확인한 코인·법안·네트워크를 다시 묻지 않고 대화 문맥을 우선한다.

## 주의

- 답변은 법률자문이나 투자 권유가 아니다.
- 공식 출처가 열리지 않으면 검증되지 않은 상태를 명시한다.
- 프로젝트·기관의 주장은 독립적으로 확인된 사실과 다를 수 있다.
- 웹을 사용할 수 없으면 최신 법안 상태·준비금·네트워크 지표를 확정하지 않는다. 알고 있는 과거 정보의 시점과 최신 검증 불가를 먼저 밝힌다.
