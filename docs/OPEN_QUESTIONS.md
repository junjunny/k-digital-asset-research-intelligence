## 기술적 잔여 위험

- URL 검증은 조회 전·리다이렉트·최종 URL의 DNS 결과를 확인하지만, 검증과 실제 연결 사이 DNS가 바뀌는 고급 DNS rebinding을 네트워크 계층에서 완전히 고정하지는 않는다. 고위험 환경에서는 별도 샌드박스·egress 방화벽이 필요하다.
- 허용된 공개 URL도 악성·오염 문서를 제공할 수 있다. 문서 내용은 계속 비신뢰 데이터로 취급한다.
