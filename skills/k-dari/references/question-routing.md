# Question Routing

기준일: 2026-11-17

K-DARI는 질문을 먼저 분류한 뒤 필요한 방법론만 사용한다. 라우터는 답변을 생성하거나 대상을 추측하지 않으며, 결정 결과는 `scripts/route_question.py`로 재현할 수 있다.

```bash
python3 scripts/route_question.py "이더리움 네트워크 평가해 줘."
```

## 우선순위

충돌할 때는 다음 순서를 적용한다.

1. 매수·매도·가격 요청을 안전 응답으로 전환
2. 법률·규제 비교
3. 백서와 명시적 법률·법안 의도
4. 스테이블코인, 네트워크, 거래소 정책처럼 명시적인 전문 유형
5. 토큰증권·RWA와 법률·정책
6. 사업모델과 코인·프로젝트
7. 대상이 없는 지시어 질문은 `AMBIGUOUS_REQUEST`

복합 질문은 하나의 `primary_type`과 필요한 `secondary_types`로 표현한다. 예를 들어 “토큰증권이 뭐야?”는 간단한 개념 설명이 주목적이므로 `CONCEPT_EXPLANATION`을 기본으로 하고 `TOKENIZED_ASSET_OR_RWA`를 보조 유형으로 둔다.

## 유형별 결정표

|---|---|---|---|---|

| `LAW_AND_REGULATION` | 특정 법률·법안·정책·규제 질문. 관할권 간 비교는 비교 유형 | 의회·관보·법령·감독기관 원문, 문서 식별, 회기, 최신 status/action, 적용 대상, 의무·예외·시행일 | 법안 이름·국가가 없으면 한 번 질문. 한국 명시 시만 한국 맥락 포함 | 보통 `STANDARD`, 단순 정의는 `QUICK`; 과거 지식으로 최신 상태 단정 금지 |
| `REGULATORY_COMPARISON` | 규제·법률·정책을 둘 이상의 관할권에서 비교 | 각 관할권 공식 원문, 목적·대상·기관 권한·사업자 의무·보호·시행 상태·비교 불가 항목 | 비교 대상이 빠지면 관할권·문서를 질문 | `STANDARD`; 이름이 비슷한 제도를 동일시하지 않음 |

## 한국 맥락 정책

다음 중 하나가 있을 때만 `include_korean_context=true`로 한다.

- 질문이 한국·국내·원화 또는 한국 기관을 명시
- 국내 이용·사업 가능성 또는 국내 거래소를 질문
- 한국 이용자에게 직접 영향을 주는 규제를 질문

단순히 사용자가 한국인이라는 이유로 모든 답변에 한국 규제를 붙이지 않는다. 코드의 플래그는 명시적 신호를 보수적으로 판정하며, 해외 변화가 국내 금융산업에 중대한 영향을 주는지는 실제 리서치 단계에서 근거와 함께 추가 판단한다.

## 한계

규칙 기반 라우터는 의미를 완전히 이해하는 분류 모델이 아니다. 새 용어·오탈자·복합 질문은 에이전트가 문맥을 검토해야 하며, 자동 결과가 부적절하면 이유를 밝히고 가장 가까운 프레임워크를 선택한다.

후속 질문에는 직전 대화에서 확인한 분석 대상·관할권·요청 깊이를 우선 적용한다. 예를 들어 LINK를 확인한 뒤 “실제 사용은?”이라고 물으면 코인명을 다시 묻지 않고 같은 프로젝트 분석을 이어간다. `include_korean_context` 역시 키워드 기반 초기 신호일 뿐이며, 최종 답변에서는 조사 결과상 실질적인 국내 영향과 무관한 한국 연결을 모두 사람이 판단한다. 별도 대화 상태 저장 서버는 필요하지 않다.
