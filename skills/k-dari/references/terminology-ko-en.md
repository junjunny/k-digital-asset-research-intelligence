# 국·영문 용어집

| English | 권장 한국어 | 주의점 |
|---|---|---|
| Security Token | 토큰증권 | 한국에서는 증권의 내용이 아니라 분산원장 기반 발행·유통 형식이라는 정책적 설명을 우선한다. |
| Tokenized Security | 토큰화 증권 | 기존 증권을 토큰 형식으로 표현한 의미가 강하나 문맥 확인이 필요하다. |
| Tokenized Deposit | 토큰화 예금 | stablecoin과 동일시하지 않는다. 은행 예금채권의 법적 성격을 확인한다. |
| Real World Asset | 실물연계자산(RWA) | 업계 용어다. 법적 자산 분류를 대신하지 않는다. |
| Custody | 수탁·보관 | 증권 계좌관리, 암호키 보관, 법적 소유권 관리를 구분한다. |
| Settlement | 결제 | 매매체결(trade execution), 청산(clearing)과 구분한다. |
| Settlement Finality | 결제완결성 | 원장 기록의 기술적 확정과 법적 최종성을 동일시하지 않는다. |
| Regulatory Sandbox | 규제 샌드박스 | 개별 특례와 일반 허용을 구분한다. |
| Investment Contract Security | 투자계약증권 | 한국 자본시장법상 정의와 해외 investment contract를 자동 대응시키지 않는다. |
| Stablecoin | 스테이블코인 | 표시가치 안정 장치, 발행자, 상환권에 따라 법적 성격이 다르다. |
| Crypto-asset Service Provider | 가상자산서비스제공자 | EU CASP와 한국 VASP의 범위가 동일하지 않다. |
| Tokenization | 토큰화 | 권리의 생성, 기존 권리의 디지털 표현, 원장 이전을 구분한다. |
